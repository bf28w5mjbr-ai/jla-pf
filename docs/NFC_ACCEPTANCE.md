# NFC 機能の受け入れ（手動）

## 前提

- Capacitor ビルド（手順は [NFC_NATIVE_BUILD.md](./NFC_NATIVE_BUILD.md)）
- テスト用 NFC タグ（本番と同型推奨）

## フェーズ 1（選手向け）

1. **タグ紐付け（ダッシュボード）**
   - 「端末で NFC 読取」が表示され、ネイティブで読取できる。
   - 読取後、入力欄に正規化済み ID が入る。
   - 「保存」で API が成功し、再表示で同じ ID が見える。
   - 既に他ユーザーに紐付いている ID では 409 相当のエラーが出る。
2. **紐付け解除**
   - 「紐付け解除」で `nfcTagId` が空になる。

## フェーズ 2（当日運用）

1. **公式出席（NFC）**: 待受開始 → タグで出席が記録される（権限のあるユーザー）。
2. **マーシャル / リザルト**: 連続で複数タグを読み取れる（iOS セッション設定に依存）。

## リグレッション

- Web（Chrome Android）では従来どおり Web NFC が動く。
- NFC 非対応ブラウザでは手入力の案内が残る。
