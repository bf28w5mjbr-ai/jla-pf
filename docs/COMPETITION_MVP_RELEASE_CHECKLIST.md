# 大会MVP リリースチェックリスト

## 事前準備
- `STRIPE_SECRET_KEY` と `STRIPE_WEBHOOK_SECRET` が本番値で設定されている
- DBマイグレーション適用済み
- 主催団体が `APPROVED` になっている

## 公開前チェック
- 大会を `DRAFT -> PUBLISHED` へ遷移できる
- 非公開大会の詳細/APIが一般ユーザーに見えない
- 種目一覧が期待通り表示される

## 個人エントリー
- 無料エントリーで完了ページまで遷移できる
- 有料エントリーで Checkout に遷移できる
- Webhook受信後に決済状態が反映される

## チームエントリーと請求
- クラブ管理者がチームエントリーを登録/更新できる
- 主催側でチーム請求を確定できる
- クラブ側で「チーム請求を支払う」からCheckout遷移できる
- 支払い後にクラブ側/主催側で状態が `SUCCEEDED` になる

## 結果運用
- 主催側の公式結果管理で行追加・保存ができる
- 不正ID（他大会/他種目）を送ると400で拒否される
- `publishedAt` 設定で結果ページに表示される
- `lockedAt` 設定後は更新不可になる

## 当日運用（不足埋め）
- 大会単位レコーダーを割り当てできる
- NFCチェックイン登録ができる
- 手入力救済で理由必須が担保される
- 召集ステータス（DNS/棄権/DSQ含む）を更新できる
- レコーダー画面で暫定結果を保存できる
- 結果ページで暫定結果がリアルタイム表示される
- 主催管理者が暫定結果を公式結果へ確定できる

## 監査ログ
- 大会ステータス変更の監査ログが記録される
- 公式結果更新の監査ログが記録される
- 決済完了時（Webhook経由）の監査ログが記録される

## リリース可否
- 上記すべてOKならMVPとして本番投入可
- 1つでもNGがあれば、原因と暫定回避策を `docs/TROUBLESHOOTING.md` に追記してから再判定
