# B-013 審査 UI での資格番号・有効期限入力（未実装）

状態: **未実装**。本 Hotfix では入力機能を追加しない。

B-003 の運用制約と同じ欠落を、別チケットとして残す。審査画面だけで番号・期限を補完し、大会の「資格要件確認済み」まで完結させる UI はまだない。

## 現状

- 審査テーブルは認定番号・発行日・有効期限を表示するだけ
- 承認 PATCH は `{ status: "APPROVED" }` のみ
- API の PATCH は `certNumber` / `issueDate` / `expiryDate` を受け付けるが、画面は送らない
- 自己申告同期は番号・期限を null で作成する

## 公開時の扱い

期限なし（または期限不明）の承認では、大会エントリーの「資格要件確認済み」にならない。開催初日まで有効な既知の期限が公式確認スナップショットと一致する必要がある。詳細は `docs/B-003-005-ui-verification-scope.md`。
